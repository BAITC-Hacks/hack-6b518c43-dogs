## Настоящий OpenAI

Пользователь сам ввёл новый ключ в локальную страницу; ключи из переписки не использовались. После отдельного разрешения шести сценариев до $3 выполнен первый прогон GPT-5.4 mini. [Все исходы, инструменты, задержки, токены и расходы](../reports/stage4/ai_integration.json).

| Сценарий | Факт первого прогона |
|---|---|
| Бюджет −30%, без звонков, максимум 5 | Ответ отклонён валидатором: invalid_response |
| Почему SMS вместо звонка | Успешно, get_campaign_evidence |
| Слабые данные всего плана | Успешно, get_plan_summary |
| Переформулированный запрос 70% бюджета | Успешно, propose_scenario; 70 000 / без call / максимум 5 |
| Переформулированный вопрос о сообщении | Успешно, get_campaign_evidence |
| Непроверенные предположения во всём плане | Ответ получен, но выбран неверный по масштабу инструмент: паспорт одной кампании |

Итого четыре полностью успешных из шести, 12 обращений к API с учётом инструментального цикла. 47 630 входных, 2 568 выходных токенов, кешированных 0, оценка $0,0472785. Задержки сценариев 4,07–8,38 с. Счётчики после перезапуска и браузерной проверки сохранились, новых платных вызовов не было: [локальный статус](../reports/stage4/status_after_browser.json). Стоимость рассчитана по опубликованным стандартным тарифам mini; это локальная оценка, не выписка биллинга.

Причина первого invalid_response не была детализирована старым обработчиком; не утверждаем, что её точный вид доказан. После прогона уточнены описания инструментов и добавлена одна ограниченная коррекция финальных ссылок. Тест с подменным SDK подтверждает третье обращение без второго пересчёта и без авто-применения. Повторный внешний прогон двух проблемных случаев ожидает отдельного разрешения. Эти локальные тесты не доказывают исправление поведения внешней модели.
