# Протокол второго этапа

Зафиксирован до новых проверок. Исходная версия: acfe1d50c10eef14df183190a302584e14f2e585.
Сохранены агент, submission и официальные проверки до изменений в reports/stage2/before.

Политика выбора, prior_floor=0.24 и планирование пилотов заморожены. Этап проверяет достоверность представления результатов и объяснений. Новые результаты не используются для подбора коэффициента уменьшения прогноза.

- Ранее исследованные прогоны: 0–9 и 42. На них анализируем ошибку прогноза, расход и контакты после возврата плана агентом.
- Отложенные проверки: официальные прогоны 10–19. Не используем для изменения модели.
- Дополнительные авторские миры: масштаб эффекта 0.2; отрицательный сдвиг; смена лучшего направления; неблагоприятный шум первых наблюдений. Фиксированные номера 50, 51, 52, по три на мир. Это диагностика, а не калибровка и не скрытое судейство.
- В отчёте сохраняем каждый исход, включая отрицательные; медиану, минимум, десятый процентиль при n >= 10, долю положительных, расходы на пилоты, время, ошибку прогноза.
- Проверяем точный расход и количество контактов по официальному результату. Уникальный охват с пилотами остаётся вероятностной оценкой: публичный интерфейс не раскрывает состав выборок.
- Числа интерфейса, сравнения и экспорта связываем с одной неизменяемой версией плана. Прогноз изменённого плана не получает измеренный результат исходного.
- Внешний AI считается проверенным только после успешного вызова с новым локальным ключом. Подменный клиент проверяет протокол и ошибки, но не качество сервиса или доступность модели.
