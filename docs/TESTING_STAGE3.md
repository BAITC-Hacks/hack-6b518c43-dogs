## Ограничения и замечания протокола

Смена лучшего направления остаётся провалом. Интервалы не откалиброваны, точная вероятность убытка не заявляется. Повторные проверки не гарантированы для каждого крупного позднего решения: может закончиться доступный пилотный бюджет. Контактный лимит и повторы изменены вместе, отдельный вклад механизмов не измерен. В собственном тестовом мире прямые исторические строки есть только для c; остальные направления используют контекстные priors, что явно уточнено в протоколе. Изначальная округлённая подпись времени исправлена по машинному timestamp; исходные байты и хеши сохранены, численные критерии неизменны.

Архивные снимки прежнего кода не пересчитываются автоматически. Нет реальных кампаний/рассылок, доступа к скрытому судейству, публичного деплоя, авторизации для внешней сети, нагрузочного теста и проверки всех ОС/браузеров. Локальные настройки/запуски/ключ не публикуются. Финальные проверки секретов и комплектности: reports/stage3/release_checks.json.
