## Настоящий OpenAI

По запросу пользователя модель по умолчанию GPT-5.4 mini; параметры и тарифы проверены по официальной документации. Пользователь ввёл новый ключ в скрытое поле локальной страницы. Ключ из переписки не использовался. .env игнорируется Git и имеет права 0600; ключ не печатается, не возвращается API и не вшит в браузерный bundle. Поле очищается при отправке. SQLite-учёт расходов сохраняется.

С явным разрешением выполнены шесть сценариев. Четыре полностью прошли, один ответ отклонён валидатором, в одном обзоре модель выбрала паспорт отдельной кампании вместо сводки плана. Подтверждены реальный пересчёт бюджета 70 000 без звонков максимум с пятью кампаниями, объяснение SMS и обзор слабых оснований. 12 обращений к модели с учётом инструментов, 47 630 входных / 2 568 выходных токенов; оценка $0,0472785. Автоматического применения и новых пилотов не было. Все исходы: reports/stage4/ai_integration.json.

После этих исходов уточнены описания инструментов и добавлена одна ограниченная попытка исправления финальных ссылок. Локальные тесты проходят; дополнительная внешняя проверка двух случаев ожидает отдельного разрешения пользователя. Бюджет исходных шести сценариев не считается разрешением на неограниченные повторы. Не объявлять все шесть успешными или исправления доказанными настоящим API.

Для проверяющего: «Обсудить план», «Подключить OpenAI», скрытый ввод собственного ключа, «Сохранить ключ локально». Терминальный вариант: python tools/configure_ai.py и ./run.sh. Проверка конфигурации: python tools/check_ai_connection.py. Платные запросы только с явным --paid-smoke; доступны --cases 0,5 для двух повторных случаев. По умолчанию локальная оценка расходов ограничена $3 и 100 вызовами; это не биллинговый лимит аккаунта. Без ключа весь ручной и конкурсный путь работает.
